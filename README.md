# diam-20k
Учебный симулятор движения, датчиков и препятствий. Для демонстрации нужны Python 3.11 или новее и NumPy.

[Полный разбор проекта и результатов](docs/project-review.md) · [Три готовых отчёта для просмотра без установки Python](examples/demo-reports.zip)

## Запуск демонстрации

Выполните в корне репозитория

```sh
python -m pip install -e .
python demo.py
```

В VS Code можно выбрать тот же интерпретатор Python, открыть `demo.py` и нажать ▶ **Run Python File**. Каждый запуск создаёт новую папку в `reports/` и печатает пути к трём HTML-файлам. Двойной щелчок открывает отчёт локально.

| Файл | Что посмотреть |
|---|---|
| `training.html` | Полный маршрут над учебными грядами. В разделе «Проход препятствий» кнопки времени ведут к каждому из восьми пролётов. Ползунок обновляет высоту над поверхностью, расход и остаток в баке. С 60 до 80 с отключён GNSS. В разделе приборов видны ошибки во время пропуска и после восстановления записи. |
| `utah.html` | Та же трасса над высотами участка Юты. В итогах указан первый шаг, на котором оболочке перестало хватать зазора. |
| `scenarios.html` | Сопоставление падения, висения, набора высоты и ветрового сноса с аналитическими решениями. Графики показывают также дрейф ИНС и действие смещения барометра. |

В демонстрации используется проверочное тело массой 2 кг. Характеристика расхода, электрическая нагрузка и объём топлива на старте задают условия учебного опыта. [Расчёт высот, ресурсов и приборов](docs/code-start.md#демонстрационные-расчёты).

Код математического ядра: `src/diam20k/`. Характеристики и неизвестные параметры: `configs/diam20k.json`.

Инструкции по установке, запуску проверок и границы модели: [первое вычислительное ядро](docs/code-start.md).

Демонстрация в браузере после установки пакета [описана в инструкции по запуску](docs/code-start.md#воспроизведение-полёта-над-картой).

Полная формулировка уравнений: [спецификация 6-DOF](docs/diam-20k-6dof-model.md).

## Сценарии полёта

Сценарий — это воспроизводимый расчёт: начальное состояние аппарата, закон внешних сил и моментов и длительность. Для каждого сценария записано точное решение, и расчёт сравнивается с ним. Код: `src/diam20k/scenarios.py`. Формулы, допущения и проверки: [описание сценариев](docs/scenarios.md).

Сценарии считаются на проверочном теле с условной геометрией. Это не характеристики ДИАМ-20К: они проверяют расчёт, а не поведение аппарата.

### Что уже есть

Во всех сценариях аппарат стартует горизонтально и неподвижно.

| Сценарий | Имя | Что задано | Результат | Отклонение от точного решения |
|---|---|---|---|---|
| Свободное падение | `free-fall` | Высота 1000 м, внешних сил нет | За 10 с высота падает до 509,67 м, скорость растёт до 98,07 м/с | 2,5·10⁻¹² |
| Висение в равновесии | `hover` | Высота 50 м; сумма тяг четырёх винтов равна весу, суммарный момент равен нулю | За 30 с аппарат остаётся на месте | 1,5·10⁻¹⁰ |
| Набор высоты | `climb` | Высота 50 м; команды тяги: висение, разгон, подъём со скоростью 4 м/с, торможение, висение | За 30 с аппарат поднимается до 110 м и останавливается | 1,3·10⁻¹⁰ |
| Висение в постоянном ветре | `wind` | Высота 50 м; тяги равновесия, воздух движется на восток со скоростью 5 м/с | За 30 с аппарат сносит на 125,8 м, скорость достигает 4,74 м/с | 2,0·10⁻¹⁰ |

Отклонение — наибольшая разность расчёта и точного решения по всем 13 компонентам состояния, в единицах СИ. Последние цифры зависят от округления на конкретной машине.

Сценарии разомкнутые: тяги заданы по времени и не зависят от состояния. Равновесие без регулятора неустойчиво: снос от ошибок округления растёт пропорционально t⁴ и за 30 с достигает 1,5·10⁻¹⁰ м.

### Запуск

После установки пакета по [инструкции](docs/code-start.md#запуск):

```sh
python -m diam20k.scenarios              # все сценарии
python -m diam20k.scenarios hover wind   # только выбранные
```

Для каждого сценария печатается строка: время, высота в конце, смещение на север и на восток, отклонение от точного решения.

### Графики

```sh
python -m diam20k.scenario_report                                 # все сценарии
python -m diam20k.scenario_report climb wind --output climb.html  # только выбранные
```

Команда создаёт `scenario-report.html` и печатает путь к нему. Файл открывается в браузере без сервера и интернета. Для каждого сценария в нём есть итоговые числа, таблица значений и шесть графиков:

- высота;
- скорость на север, на восток и вверх;
- смещение от точки старта;
- ориентация: крен, тангаж, курс;
- внешние силы в осях корпуса, без силы тяжести;
- отклонение от точного решения на логарифмической шкале.

Курсор времени общий: при наведении на любой график значения показывают все графики сразу. Кнопка «Пуск» проигрывает сценарий, ползунок перемещает время вручную.

### Использование из кода

```python
from diam20k.scenarios import climb, deviation, run

scenario = climb(height_gain_m=30.0, climb_rate_m_s=3.0)
time_s, states = run(scenario)   # массивы формы (n,) и (n, 13)
altitude_m = -states[:, 2]       # высота h = −D
print(altitude_m[-1], deviation(scenario, time_s, states))
```

Каждый сценарий — функция с параметрами: высота, длительность, шаг, тело, координаты винтов. Свой сценарий создаётся через `Scenario(имя, название, body, initial_state, loads, duration_s, dt_s)`; `loads(time_s, state)` возвращает силу и момент в связанных осях, без тяжести, момент относительно ЦМ.

### Условные параметры

| Параметр | Значение |
|---|---|
| Масса | 2 кг |
| Тензор инерции | diag(2, 3, 4) кг·м² |
| Точки приложения тяги четырёх винтов | (±0,5; ±0,7; 0) м от ЦМ |
| Произведения C_D·A по осям x, y, z | 0,2; 0,4; 0,6 м² |
| Плотность воздуха | 1,225 кг/м³ |
| Ускорение свободного падения | 9,80665 м/с² |

Тело, координаты винтов и площади сопротивления передаются в сценарии аргументами, поэтому измеренные значения можно будет подставить без изменения кода.

### Проверки

```sh
python -m unittest tests.test_scenarios tests.test_scenario_report -v
```

Тесты этих модулей проверяют совпадение каждого сценария с точным решением, баланс сил и моментов в равновесии, в том числе при смещённом центре масс, знаки осей, повторяемость запусков, отказ на неверных параметрах, данные для графиков.

### Ограничения

- Команда сценария — фактическая тяга винта в ньютонах, а не команда газа.
- Тяга подъёмных винтов направлена строго по −z корпуса, их реактивные моменты приняты нулевыми.
- Маршевого двигателя, крыла и рулей в сценариях нет.
- Сопротивление корпуса задано условными площадями и приложено в ЦМ.
- Ветер постоянный, контакта с землёй нет.
- Регуляторов высоты и ориентации пока нет: это следующий этап.

# ДИАМ-20К: описание аппарата и датчики учебного проекта

## 1. Назначение проекта

Проект посвящён созданию цифровой модели гибридного БПЛА ДИАМ-20К.
## 2.  Описание аппарата

![ДИАМ-20К — фотография с официального сайта производителя](https://www.diam-aero.ru/diam20k_view1.jpg)

Источник фотографии: [ДИАМ-АЭРО, страница ДИАМ-20К](https://www.diam-aero.ru/bas_diam20k.html). [Открыть фотографию отдельно](https://www.diam-aero.ru/diam20k_view1.jpg).

ДИАМ-20К — беспилотный аппарат самолётного типа с вертикальным взлётом и посадкой. Он выполнен по аэродинамической схеме «утка»: горизонтальное переднее оперение расположено перед основным крылом. Для вертикального взлёта и посадки предусмотрены четыре электродвигателя; в состав силовой установки также входит двигатель внутреннего сгорания со стартер-генератором.


## 3. Основные характеристики

Значения ниже опубликованы на [сайте производителя](https://www.diam-aero.ru/bas_diam20k.html)

| Характеристика | Значение |
|---|---|
| Тип аппарата | Самолётный, с вертикальным взлётом и посадкой |
| Аэродинамическая схема | «Утка» |
| Максимальная взлётная масса | До 30 кг |
| Размах крыла | 4 м |
| Длина | 2 м |
| Масса полезной нагрузки | 3–5 кг |
| Двигатель внутреннего сгорания | Рабочий объём 40 см³, мощность 3,7 л.с. |
| Электродвигатели для взлёта и посадки | 4 шт. |
| Максимальная скорость | 40 м/с, или 144 км/ч |
| Крейсерская скорость | 22–24 м/с |
| Максимальная дальность | 800 км |
| Максимальная высота | 2000 м; система отсчёта на странице не уточнена |
| Взлёт и посадка | Вертикальные |
| Размер площадки | 7 × 7 м |
| Ограничение по скорости ветра | Не более 15 м/с |
| Температура окружающей среды | От −30 до +40 °C |

## 4. Датчики, выбранные для имитации

Типовой состав сопоставлен с [рекомендациями PX4 для бортовых датчиков](https://docs.px4.io/v1.18/en/sensor/index): инерциальные датчики, магнитометр, барометр, GNSS и измерение воздушной скорости для самолётов и VTOL.

| Датчик | Имитируемый выход | Единицы | Назначение | Частота выдачи в проекте |
|---|---|---|---|---|
| Трёхосевой гироскоп | Угловые скорости по трём осям | рад/с | Стабилизация вращения и оценка ориентации | 200 Гц |
| Трёхосевой акселерометр | Удельная сила по трём осям | м/с² | Оценка движения и ориентации | 200 Гц |
| Трёхосевой магнитометр | Компоненты магнитного поля | мкТл | Коррекция оценки курса | 50 Гц |
| Барометр | Статическое давление | Па | Оценка высоты по атмосферному давлению | 25 Гц |
| GNSS-приёмник, GPS/ГЛОНАСС | Широта, долгота, высота и скорость относительно земли | градусы, м, м/с | Навигация и определение положения | 5 Гц |
| Приёмник воздушного давления с датчиком перепада | Разность полного и статического давления | Па | Оценка воздушной скорости | 50 Гц |

Частоты являются начальными настройками симуляции. Они не взяты из паспорта ДИАМ-20К. Гироскоп и акселерометр логически моделируются отдельно, хотя физически обычно входят в один инерциальный измерительный модуль — IMU.

## 5. Общая модель измерений

Динамическая модель хранит истинное состояние аппарата. Датчики формируют отдельные измерения этого состояния. Общая запись для канала имеет вид `yₖ = h(x(tₖ − τ), e) + b + ηₖ`.

Здесь h — функция идеального измерения, x — состояние аппарата, e — условия среды, τ — задержка, b — смещение, η — шум. Частота выдачи задаёт моменты t_k. При необходимости к результату применяются насыщение и квантование.

## 6. Дополнительные каналы

Дальномер вычисляет первое пересечение луча с поверхностью или препятствием. Расходомер, тахометр и электрические каналы поддерживают разбор внешних журналов. Для температуры двигателя отдельной модели пока нет.

| Датчик | Возможное применение |
|---|---|
| Дальномер вниз | Расстояние до земли при посадке с учётом наклона и рельефа |
| Датчики оборотов двигателей | Контроль работы силовой установки |
| Измерители напряжения и тока батареи | Контроль энергопотребления |
| Датчики температуры ДВС | Тепловое состояние двигателя |
| Датчик уровня или расхода топлива | Оценка остатка топлива и продолжительности полёта |

Расчёт идеальных показаний и запись на проектных частотах доступны в
[карте сценариев](docs/code-start.md#связь-сценария-карты-и-измерений).
Расход топлива можно вычислить по синхронному журналу расходомера или режимов
двигателя с известным удельным расходом.
