# ДИАМ-20К: описание аппарата и датчики учебного проекта

## 1. Назначение проекта

Проект посвящён созданию цифровой модели гибридного БПЛА ДИАМ-20К.
## 2.  Описание аппарата

![ДИАМ-20К — фотография с официального сайта производителя](https://www.diam-aero.ru/diam20k_view1.jpg)

Источник фотографии: [ДИАМ-АЭРО, страница ДИАМ-20К](https://www.diam-aero.ru/bas_diam20k.html). [Открыть фотографию отдельно](https://www.diam-aero.ru/diam20k_view1.jpg).

ДИАМ-20К — беспилотный аппарат самолётного типа с вертикальным взлётом и посадкой. Он выполнен по аэродинамической схеме «утка»: горизонтальное переднее оперение расположено перед основным крылом. Для вертикального взлёта и посадки предусмотрены четыре электродвигателя; в состав силовой установки также входит двигатель внутреннего сгорания со стартер-генератором.

## 4. Датчики, выбранные для имитации

Типовой состав сопоставлен с [рекомендациями PX4 для бортовых датчиков](https://docs.px4.io/v1.18/en/sensor/index): инерциальные датчики, магнитометр, барометр, GNSS и измерение воздушной скорости для самолётов и VTOL.

| Датчик | Имитируемый выход | Единицы | Назначение | Частота выдачи в проекте |
|---|---|---|---|---|
| Трёхосевой гироскоп | Угловые скорости по трём осям | рад/с | Стабилизация вращения и оценка ориентации | 200 Гц |
| Трёхосевой акселерометр | Удельная сила по трём осям | м/с² | Оценка движения и ориентации | 200 Гц |
| Трёхосевой магнитометр | Компоненты магнитного поля | мкТл | Коррекция оценки курса | 50 Гц |
| Барометр | Статическое давление | Па | Оценка высоты по атмосферному давлению | 25 Гц |
| GNSS-приёмник, GPS/ГЛОНАСС | Широта, долгота, высота и скорость относительно земли | градусы, м, м/с | Навигация и определение положения | 5 Гц |
| Приёмник воздушного давления с датчиком перепада | Разность полного и статического давления | Па | Оценка воздушной скорости | 50 Гц |

Частоты являются начальными настройками симуляции. Они не взяты из паспорта ДИАМ-20К. Гироскоп и акселерометр логически моделируются отдельно, хотя физически обычно входят в один инерциальный измерительный модуль — IMU.

### 4.1. Гироскоп

Измеряет скорость вращения корпуса вокруг связанных осей. Сам по себе не выдаёт крен, тангаж и курс.

Идеальный выход при совпадении осей датчика и корпуса: вектор угловой скорости из 6-DOF модели. При другом монтаже применяется преобразование координат. В дальнейшем добавляются смещение нуля, шум и ограничение диапазона.

### 4.2. Акселерометр

Измеряет удельную силу, а не просто ускорение координат. Для датчика в центре масс:

\[
\mathbf f^B=R^T(\mathbf a^N-\mathbf g^N).
\]

Здесь R переводит связанные координаты в NED, a — ускорение относительно земли, g — вектор ускорения свободного падения.

При осях корпуса «вперёд, вправо, вниз» горизонтально неподвижный поддерживаемый аппарат имеет идеальное показание примерно (0, 0, −9,81) м/с². В свободном падении идеальное показание равно нулю. Если датчик расположен не в центре масс, необходимо дополнительно учитывать ускорения из-за вращения.

### 4.3. Магнитометр

Измеряет вектор магнитного поля в своих осях. Для идеальной модели берётся магнитное поле в точке полёта и переводится в систему датчика. Курс вычисляется с учётом ориентации аппарата и магнитного склонения; магнитометр не измеряет курс напрямую.

### 4.4. Барометр

Выдаёт атмосферное давление. Высота получается из модели атмосферы с выбранным опорным давлением. Барометрическая высота не равна расстоянию до поверхности земли. Сначала имитируется давление по высоте, затем добавляются смещение и шум.

### 4.5. GNSS

Выдаёт положение и скорость относительно земли. Для преобразования локальных координат NED в широту, долготу и высоту задаётся географическая точка начала моделирования. Для первой версии принимается эллипсоидальная высота WGS-84; высота над уровнем моря потребует модели геоида.

GNSS-скорость отличается от воздушной скорости при наличии ветра. Задержка, погрешности и потеря решения в дальнейшем моделируются отдельно.

### 4.6. Датчик воздушного давления

Система включает приёмник полного давления, отбор статического давления и датчик их разности. При корректном обтекании и малой скорости по сравнению со скоростью звука:

\[
\Delta p\approx\frac12\rho V_a^2,
\qquad V_a\approx\sqrt{2\Delta p/\rho}.
\]

Здесь ρ — плотность воздуха, V_a — модуль скорости относительно воздушной массы. Формула является начальным приближением при согласованном направлении приёмника и набегающего потока. При больших углах атаки и скольжения, в переходе и в обдуве винтов нужны поправки или признак недостоверного измерения. Висение не следует трактовать как режим точного измерения этим датчиком.

## 5. Общая модель измерений

Динамическая модель хранит истинное состояние аппарата. Датчики формируют отдельные измерения этого состояния:

\[
\mathbf y_k=h(\mathbf x(t_k-\tau),\mathbf e(t_k-\tau))+\mathbf b_k+\boldsymbol\eta_k.
\]

Здесь h — функция идеального измерения, x — состояние аппарата, e — условия среды, τ — задержка, b — смещение, η — шум. Частота выдачи задаёт моменты t_k. При необходимости к результату применяются насыщение и квантование.

## 6. Возможные расширения

Следующие датчики пока не включены в базовую версию:

| Датчик | Возможное применение |
|---|---|
| Дальномер вниз | Расстояние до земли при посадке с учётом наклона и рельефа |
| Датчики оборотов двигателей | Контроль работы силовой установки |
| Измерители напряжения и тока батареи | Контроль энергопотребления |
| Датчики температуры ДВС | Тепловое состояние двигателя |
| Датчик уровня или расхода топлива | Оценка остатка топлива и продолжительности полёта |
