# Сценарии полёта

Модуль `src/diam20k/scenarios.py` задаёт воспроизводимые сценарии для механического ядра: начальное состояние, закон внешних нагрузок и длительность. Для каждого сценария записано точное решение, с которым сравнивается расчёт.

Сейчас готовы четыре сценария: свободное падение, висение в равновесии, набор высоты и висение в ветре. Все они разомкнутые: тяги заданы по времени и не зависят от состояния. Регуляторы высоты и ориентации — следующий этап.

Масса, инерция, координаты винтов и площади сопротивления в модуле условные. Это проверочное тело, а не ДИАМ-20К.

## Запуск

После установки пакета по [инструкции](code-start.md#запуск):

```sh
python -m diam20k.scenarios              # все сценарии
python -m diam20k.scenarios hover wind   # только выбранные
```

Вывод при настройках по умолчанию:

```text
Проверочное тело и условная геометрия, не параметры ДИАМ-20К.
free-fall: Свободное падение. Время 10 с, высота 509.668 м, смещение на север 0.000 м, на восток 0.000 м, отклонение от точного решения 2.5e-12
hover: Висение в равновесии. Время 30 с, высота 50.000 м, смещение на север 0.000 м, на восток 0.000 м, отклонение от точного решения 1.5e-10
climb: Набор высоты. Время 30 с, высота 110.000 м, смещение на север 0.000 м, на восток 0.000 м, отклонение от точного решения 1.3e-10
wind: Висение в постоянном ветре. Время 30 с, высота 50.000 м, смещение на север 0.000 м, на восток 125.804 м, отклонение от точного решения 2.0e-10
```

Отклонение — наибольшая по модулю разность расчёта и точного решения по всем 13 компонентам состояния и всем моментам времени, в единицах СИ. Последние цифры зависят от округления на конкретной машине.

Из Python:

```python
from diam20k.scenarios import climb, deviation, run

scenario = climb(height_gain_m=30.0, climb_rate_m_s=3.0)
time_s, states = run(scenario)   # массивы формы (n,) и (n, 13)
altitude_m = -states[:, 2]       # высота h = −D
print(altitude_m[-1], deviation(scenario, time_s, states))
```

## Как устроен сценарий

`Scenario` хранит всё, что нужно для повторения расчёта:

| Поле | Содержание |
|---|---|
| `name`, `title` | Имя для командной строки и название |
| `body` | Масса и тензор инерции (`RigidBody`) |
| `initial_state` | 13 компонентов: N, E, D; u, v, w; q0…q3; p, q_body, r |
| `loads(time_s, state)` | Сила и момент в связанных осях, без тяжести, момент относительно ЦМ |
| `duration_s`, `dt_s` | Длительность и наибольший шаг интегрирования |
| `exact(time_s)` | Точное решение формы (n, 13) или `None`, если формулы нет |

Формат состояния и нагрузок тот же, что в `step_rk4`: СИ, оси NED и «вперёд, вправо, вниз», тяга вверх — отрицательная сила по оси z корпуса.

`run(scenario)` интегрирует сценарий методом RK4 на равномерной сетке. Число шагов округляется вверх, поэтому шаг не больше `dt_s`, а последняя точка приходится точно на конец сценария. `deviation(scenario, time_s, states)` возвращает отклонение от точного решения.

Свой сценарий создаётся так же: `Scenario("имя", "название", body, initial_state, loads, duration_s, dt_s)`.

## Условные параметры

| Параметр | Значение | Откуда |
|---|---|---|
| Масса | 2 кг | Проверочное тело из [описания ядра](code-start.md#условный-пример-проверки-механики) |
| Тензор инерции | diag(2, 3, 4) кг·м² | То же |
| Точки приложения тяги четырёх винтов | (±0,5; ±0,7; 0) м от ЦМ | Выбраны симметрично |
| Произведения C_D·A по осям x, y, z | 0,2; 0,4; 0,6 м² | Выбраны произвольно |
| Плотность воздуха | 1,225 кг/м³ | Стандартная атмосфера у уровня моря |
| Ускорение свободного падения | 9,80665 м/с² | Как в [спецификации](diam-20k-6dof-model.md) |

Тело, координаты винтов и площади передаются в сценарии аргументами. Когда появятся измеренные значения, сценарии можно будет запустить с ними без изменения кода.

## Сценарии

Во всех сценариях аппарат стартует горизонтально и неподвижно: q = (1, 0, 0, 0), скорости нулевые, высота h = −D.

### Свободное падение, `free-fall`

Внешних нагрузок нет, действует только тяжесть. Старт с высоты 1000 м, длительность 10 с.

```math
D(t) = D_0 + \frac{g t^2}{2}, \qquad w(t) = g t
```

Контакта с землёй в модели нет, поэтому сценарий не создаётся, если за заданное время аппарат опустится ниже D = 0.

### Висение в равновесии, `hover`

Горизонтальный аппарат, сумма тяг равна весу, суммарный момент равен нулю. Каждый винт тянет вдоль −z корпуса. Для винта в точке (xᵢ, yᵢ, zᵢ) с тягой Tᵢ момент относительно ЦМ равен (−yᵢTᵢ, xᵢTᵢ, 0), поэтому условия равновесия такие:

```math
\sum_i T_i = m g, \qquad \sum_i y_i T_i = 0, \qquad \sum_i x_i T_i = 0
```

Уравнений три, тяг четыре. Функция `hover_thrusts` берёт решение с наименьшей суммой квадратов тяг. Для симметричного расположения это Tᵢ = mg/4, для проверочного тела — 4,903 Н на винт. При смещённом центре масс тяги получаются разными: больше нагружены винты, которые ближе к ЦМ. Если это решение требует отрицательной тяги, функция сообщает об ошибке.

Точное решение — неизменное начальное состояние.

Равновесие без регулятора неустойчиво. Остаточный момент от округления, около 10⁻¹⁵ Н·м, медленно наклоняет аппарат, тяга получает горизонтальную составляющую, и снос растёт пропорционально t⁴: 1,5·10⁻¹⁰ м за 30 с, 3,8·10⁻⁸ м за 120 с. Для длительного висения нужен регулятор ориентации.

### Набор высоты, `climb`

Последовательность команд тяги: висение, разгон вверх, подъём с постоянной скоростью, торможение, висение на новой высоте. По умолчанию аппарат поднимается с 50 до 110 м за 30 с со скоростью 4 м/с.

Тяги всех винтов меняются одинаково:

```math
T_i(t) = T_i^{0}\left(1 + \frac{a(t)}{g}\right)
```

Здесь Tᵢ⁰ — тяги равновесия, a(t) — заданное вертикальное ускорение. Сумма тяг равна m(g + a), а момент остаётся нулевым. Ускорение a(t) кусочно-линейное: импульс разгона имеет форму трапеции с фронтами длительностью t_r и полкой длительностью t_p на уровне a, импульс торможения зеркален ему.

```math
V = a\,(t_p + t_r), \qquad \tau = t_p + 2 t_r, \qquad \Delta h = V\,(\tau + t_c)
```

V — скорость подъёма, τ — длительность импульса, t_c — время подъёма с постоянной скоростью. Сценарий получает Δh, V, a и t_r и находит из этих формул t_p и t_c. По умолчанию a = 1 м/с², t_r = 1 с, откуда t_p = 3 с, τ = 5 с, t_c = 10 с; до и после манёвра аппарат висит по 5 с.

Точное решение получается двукратным интегрированием a(t) по участкам: скорость на каждом участке — квадратичная функция времени, высота — кубическая.

Команда меняется без скачков, потому что тяга винта не может измениться мгновенно. Есть и вычислительная причина: при линейном на шаге ускорении RK4 воспроизводит движение точно. Для этого узлы команды должны попадать на сетку времени. Если узел оказывается внутри шага, отклонение растёт: например, до 2·10⁻⁵ м при шаге 0,007 с.

### Висение в постоянном ветре, `wind`

Тяги те же, что в равновесии. Ветер постоянный; вектор W показывает, куда движется воздух. По умолчанию W = (0, 5, 0) м/с: воздух движется на восток.

Сопротивление корпуса берётся по формуле для висения из [спецификации, раздел 6](diam-20k-6dof-model.md#6-воздушная-скорость-и-аэродинамика):

```math
v_a^B = v^B - R^T W^N, \qquad
F_j = -\tfrac12\,\rho\,(C_D A)_j\,v_{a,j}\,|v_{a,j}|, \quad j = x, y, z
```

Сила приложена в ЦМ и момента не создаёт. Аппарат остаётся горизонтальным, связанные оси совпадают с NED, и движение по каждой оси описывается отдельно:

```math
k_j = \frac{\rho\,(C_D A)_j\,|W_j|}{2m}, \qquad
v_j(t) = W_j\,\frac{k_j t}{1 + k_j t}, \qquad
x_j(t) = W_j\left(t - \frac{\ln(1 + k_j t)}{k_j}\right)
```

Скорость аппарата стремится к скорости ветра, но не достигает её. По умолчанию k = 0,6125 1/с; за 30 с аппарат набирает 4,74 м/с и смещается на 125,8 м к востоку. Высота не меняется.

## Допущения и ограничения

- Проверочное тело и условная геометрия. Результаты проверяют расчёт, а не поведение ДИАМ-20К.
- Команда сценария — фактическая тяга винта в ньютонах, а не команда газа.
- Тяга каждого подъёмного винта направлена строго по −z корпуса. Реактивные моменты винтов приняты нулевыми: их знаки и величины неизвестны.
- Маршевого двигателя, крыла и рулей в сценариях нет.
- Сопротивление корпуса задано условными площадями и приложено в ЦМ. Обдув винтами не учитывается.
- Ветер постоянный по времени и пространству. Вертикальная составляющая ветра не меняет тягу винтов.
- Контакта с землёй нет.
